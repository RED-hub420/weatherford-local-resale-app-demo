# Weatherford Local Resale & Thrift App Demo — Sales v5

A customer-first static web app demo built to feel like a believable resale shopping experience on the front end, with a strong owner dashboard on the admin side.

## What changed in v5
- Removed the meta sales-deck style intro screen
- Opened the app directly into a real-feeling customer shopping experience
- Reworked the customer side to feel less like a dashboard and more like a store
- Replaced cluttered product presentation with cleaner curated demo inventory
- Tightened the owner/admin side so it still sells the operational value

## What this includes
- Customer shopping home
- Inventory browser with search and category filters
- Product detail modal
- Save item / wishlist flow
- Make offer flow
- Add to cart and checkout flow
- Orders, messages, and account screens
- Admin dashboard
- Inventory management
- Orders, customers, payments, analytics, and settings
- Local browser persistence via localStorage

## Files
- `index.html`
- `styles.css`
- `app.js`
- `assets/images/`

## Demo notes
- This is front-end only
- Data is simulated
- Changes persist locally in the same browser
- Use **Reset Demo** from the admin side to restore original data

## Recommended presentation flow
1. Open the app on the customer side first
2. Show browsing, saving, offers, and checkout
3. Then switch to the admin side
4. Show inventory, orders, messages, and the owner dashboard

This version is meant to feel solid and believable, not over-explained.
