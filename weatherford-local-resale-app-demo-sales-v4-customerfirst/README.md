# Weatherford Local Resale & Thrift App Demo — Sales v3

Netlify-ready static demo for a resale/thrift web app concept built to help Seth visualize a real customer-facing storefront plus an admin operating system.

## What this version adds
- Stronger sales framing throughout
- Better first-screen messaging for Seth
- More realistic “live today” admin dashboard
- Hot inventory section and recent activity feed
- Stronger customer-home story around conversion and treasure-hunt shopping
- Updated local storage key so this version opens clean in the browser

## What this includes
- Customer portal demo
- Admin portal demo
- Searchable demo inventory
- Cart and checkout flow
- Offer flow
- Orders, payments, customers, analytics, opportunity, and messages screens
- Local browser persistence via localStorage

## How to deploy
1. Unzip the folder if needed.
2. Drag the full folder into Netlify manual deploy.
3. Open the site.

## Demo notes
- This is front-end only.
- Data is simulated.
- Inventory edits, orders, and cart activity persist in that browser using localStorage.
- Use the Reset Demo button in the top bar to restore the original sales demo data.
